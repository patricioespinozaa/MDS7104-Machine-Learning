# MDS7104 - Machine Learning

This repository contains the assignments completed during the course **MDS7104: Machine Learning**, taught by **Francisco Vásquez L.** at the **Faculty of Physical and Mathematical Sciences, University of Chile**, as part of the **Master’s in Data Science**.

The course focused on machine learning techniques, dimensionality reduction, tree-based models, and neural networks, covering topics such as:

- Linear regression and probabilistic models  
- Classification algorithms  
- Model selection using AIC and BIC  
- Dimensionality reduction techniques  
- Support Vector Machines  
- Tree-based models  

## Assignments

- **T1:** Regresión Lineal  
- **T2:** Naive Bayes  
- **T3:** Modelos de Clasificación  
- **T4:** Modelos de Clasificación, uso de AIC y BIC  
- **T5:** Reducción de dimensionalidad y SVC  
- **T6:** Modelos basados en árboles
